إعداد حساب NetBird والمزامنة

اربط Personal Access Token لقراءة الأجهزة من NetBird Cloud أو خادمك الخاص. الربط هنا يقرأ القائمة؛ الوصول إلى الأجهزة يحتاج NetBird شغّالًا على سيرفر DeskSwarm وسياسة شبكة تسمح بـSSH. «غير مجهّز» يعني أنه لم يُربط ويُختبر مع Docker بعد، حتى لو كان Online.

Proxmox · إنشاء CT سريع

استخدم سيرفر Proxmox المربوط عبر SSH. ينشئ CT غير مميّز مع nesting، ويثبّت Docker وSSH ويربطه تلقائيًا لتشغيل أجهزة DeskSwarm داخله.

إيقاف CT أو إعادة تشغيله يؤثر على كل الكمبيوترات داخله. الإيقاف هنا سليم بدون إجبار أو حذف.

الأسماء تُرقّم تلقائيًا بدون تكرار. إنشاء الكمبيوترات متاح للـCTs المربوطة بسيرفر Docker، والنتائج الجزئية محفوظة.

إنشاء CT جديد وإعدادات Proxmox

الشبكة تستخدم DHCP. إنشاء CT يستهلك الموارد المحددة، وبناء أول صورة قد يستغرق دقائق. لا تُحذف الموارد تلقائيًا عند التعطل.

الإعدادات الافتراضية للربط

تُملأ عند اختيار جهاز من NetBird؛ يمكنك تعديلها لكل سيرفر. مفتاح SSH وبصمة المضيف يظلان مطلوبين للتحقق من هوية الجهاز.
